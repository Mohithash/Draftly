# Draftly

**Say it well.** A bring‑your‑own‑key AI writing assistant for messages and email.

- ↩️ **Reply** to anything you received — paste it or attach a screenshot — and get three angles (warm / concise / firm).
- ✍️ **Rewrite** in a tone: friendly, professional, casual, assertive, apologetic, enthusiastic, neutral.
- 🧾 **Summarise** long threads into TL;DR, key points and actions.
- 🌐 **Translate** naturally, literally or formally.
- 🧱 **Expand** notes into full text · ✂️ **Shorten** to half, a paragraph, or one line.
- Copy or share in one tap; on‑device history.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).
